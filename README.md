# Elencus - Logic Protocol Simulation

Elencus is a complex, cyberpunk-themed logic puzzle game built with Svelte, TypeScript, and Tailwind CSS. The game challenges players to solve truth tables by connecting basic logic gates (AND, OR, NOT, XOR, etc.) within a grid-based hardware simulation environment.

## Features

- **Cyberpunk / Claymorphism UI**: A visually stunning, adaptive interface with neon glows, chamfered edges, and 3D grid backgrounds.
- **Adaptive Responsive Design**: The UI automatically shifts from a desktop-optimized sidebar layout to a mobile-friendly bottom-bar layout, allowing for optimal gameplay on any device.
- **Circuit Simulation Engine**: Build and validate complex logic circuits in real-time.
- **Interactive Grid System**: Place nodes, route wires, and manage your hardware resources.
- **Progress Tracking**: Tracks your optimal configurations (par components) across all stages.

## Getting Started

1. Clone the repository:
   ```bash
   git clone https://github.com/FerrDxD/elenchus.git
   ```
2. Navigate to the project directory:
   ```bash
   cd elenchus
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Run the development server:
   ```bash
   npm run dev
   ```
