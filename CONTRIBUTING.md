# Contributing to Elencus

First off, thank you for considering contributing to Elencus! It's people like you that make open-source such a great community.

## How Can I Contribute?

### Reporting Bugs
If you find a bug, please create an issue on GitHub. Include as much detail as possible:
* Describe the expected behavior and the actual behavior.
* Provide steps to reproduce the issue.
* Specify your OS, browser, and any relevant environment details.

### Suggesting Enhancements
Have an idea to make the game better? We love new ideas!
* Open an issue explaining your suggestion.
* Detail why it would be useful and how it aligns with the cyberpunk aesthetic and logic puzzle theme.

### Pull Requests
1. Fork the repo and create your branch from `main`.
2. If you've added code that should be tested, add tests.
3. If you've changed APIs, update the documentation.
4. Ensure the test suite passes.
5. Make sure your code adheres to the existing coding style (Svelte + TypeScript + Tailwind).
6. Issue that pull request!

## Code Style
* We use **TypeScript** strictly. Avoid `any` where possible.
* UI components should follow the Cyberpunk / Claymorphism design system variables defined in `src/app.css`.
* Follow the mobile-first responsive approach for any new UI changes.
